# PLAY-BASED ACADEMIC OBJECTIVES

Through a play-based academic approach, we aim to achieve our program goal and objectives by offering children various hands-on learning opportunities to become:

- Critical thinkers
- Problem Solvers
- Decision Makers
- Passionate About Learning
- Able To Get Along With Others
- Kindergarten Ready
